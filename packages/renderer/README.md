# @dopejs/deckle-renderer

Backend-neutral retained picture contract, reference compositor, LOD policy, and texture budget for
Deckle.

Part of [Deckle](https://deckle.dopejs.com), an infinite-canvas runtime for AI-generated web
artifacts.

```bash
pnpm add @dopejs/deckle-renderer
```

- [Usage guide](https://deckle.dopejs.com/docs/usage/)
- [Technical design](https://deckle.dopejs.com/docs/design/)
