# @dopejs/deckle-runtime

Controlled runtime message protocol, epochs, quotas, and capability-guarded host bridge for Deckle.

Part of [Deckle](https://deckle.dopejs.com), an infinite-canvas runtime for AI-generated web
artifacts.

```bash
pnpm add @dopejs/deckle-runtime
```

- [Technical design](https://deckle.dopejs.com/docs/design/)
