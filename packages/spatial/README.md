# @dopejs/canvas-spatial

Spatial indexes and the naive differential oracle for dope-canvas visibility queries.

Part of [dope-canvas](https://canvas.dopejs.com), an infinite-canvas runtime for AI-generated web
artifacts.

```bash
pnpm add @dopejs/canvas-spatial
```
