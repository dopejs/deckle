# @dopejs/deckle-spatial

Spatial indexes and the naive differential oracle for Deckle visibility queries.

Part of [Deckle](https://canvas.dopejs.com), an infinite-canvas runtime for AI-generated web
artifacts.

```bash
pnpm add @dopejs/deckle-spatial
```
