# @dopejs/deckle-artifact

Artifact source, revisions, interaction tree, and deterministic serialization for Deckle.

Part of [Deckle](https://deckle.dopejs.com), an infinite-canvas runtime for AI-generated web
artifacts.

```bash
pnpm add @dopejs/deckle-artifact
```

- [Technical design](https://deckle.dopejs.com/docs/design/)
